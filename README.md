# Portfólio Web — Kauê Lucas

Este projeto foi desenvolvido para a disciplina de Desenvolvimento Web com o objetivo de criar e publicar um portfólio pessoal utilizando HTML e CSS.

## Sobre o projeto

O site apresenta informações profissionais e acadêmicas, incluindo:

- apresentação pessoal
- seção "sobre mim"
- habilidades
- projetos
- contato

O layout foi desenvolvido com foco em organização, design moderno e responsividade para dispositivos móveis e desktop.

---

## Tecnologias utilizadas

- HTML5
- CSS3
- Git
- GitHub
- VS Code

---

## Estrutura do código

### index.html
Arquivo responsável pela estrutura da página.

Nele foram criadas:
- seções do portfólio
- textos
- links
- organização do conteúdo

### style.css
Arquivo responsável pela estilização do site.

Nele foram utilizados:
- cores personalizadas
- responsividade
- flexbox
- efeitos hover
- gradientes
- media queries

### pasta imagens
Armazena:
- foto de perfil
- imagem de fundo

---

## Responsividade

O projeto utiliza media queries para adaptar o layout em diferentes tamanhos de tela, garantindo melhor experiência em celulares e computadores.

---

## Objetivo acadêmico

Este projeto foi criado para praticar:
- estruturação HTML
- estilização com CSS
- versionamento com Git
- publicação de sites
